Este livro ensina métodos numéricos para engenharia a um leitor que trabalha **com** um agente de IA. O agente escreve o código. Você precisa entender a ideia de cada método, especificar o que pede, **verificar** o resultado e reconhecer quando o método falha.

## Como cada capítulo é organizado

Todos os capítulos seguem as mesmas sete seções:

1. **Problema de engenharia**: um caso real que motiva o método.
2. **A ideia em uma imagem**: a intuição geométrica, antes de qualquer equação.
3. **Formulação matemática**: a dedução e a análise de erro.
4. **À mão**: duas ou três iterações no papel.
5. **Explore**: gráficos e controles interativos para variar os parâmetros.
6. **Trabalhando com o agente**: especificar, gerar e verificar o código.
7. **Quando falha**: os casos em que o método, ou o código do agente, erra.

## Como ler

- **No navegador:** cada página tem um botão para executar o código ali mesmo, sem instalar nada.
- **No Colab:** cada capítulo tem um link para abrir o notebook no Google Colab.
- **No seu computador:** clone o repositório e instale as dependências com `pip install -r requirements.txt`.
- **Em PDF:** [baixe o livro em PDF](https://vnikoofard.github.io/calculo-numerico-livro/calculo-numerico.pdf). A versão impressa traz as mesmas figuras, em forma estática, e é atualizada a cada nova versão do site. O botão **Baixar PDF**, no topo de todas as páginas, leva ao mesmo arquivo.

Comece pela página [Demonstração dos padrões](./demonstracao.ipynb), que mostra os gráficos e os controles interativos usados no livro.

Estas notas partem do livro *Numerical Methods for Engineers*, de Steven Chapra e Raymond Canale, que continua sendo a leitura de apoio.
